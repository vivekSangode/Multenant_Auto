## 1. Summary

1. **Platform admin model:** `PlatformAdmin` + company scope; the PLATFORM-domain rows of `tbl_role`, `tbl_permission`, `tbl_role_permission`; permission seed; `PlatformAccessResolver` without global bypass; `@RequiresPlatformPermission`; `denyAll` default.
2. **Platform admin management:** invite, suspend, roles (in the platform realm, via the identity-sync outbox), scope; `/platform/me` with permissions and scope.
3. **Company lifecycle APIs** under `/api/v1/platform/admin/companies/**` on the PHASE_02 `CompanyService`.
4. **Database-driven module catalog** (`tbl_module`, `tbl_module_dependency`) with seed, services, cycle detection, internal module API, consistency self-check; `ModuleCatalog` and the YAML list retired.
5. **Audit** extension and the trusted-IP fix.

Size estimate: 9 tasks (+2 early slices), about 60–80 files, about 25 new test classes.
