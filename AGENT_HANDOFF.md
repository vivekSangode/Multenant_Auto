## 6. How several agents work together

1. **One agent = one task area.** The owner states the area at the start, e.g. "PHASE_02 schema", "PHASE_03 Keycloak", or "review only". Do not edit files outside your area.
2. **Before editing**, check [PHASE_STATUS_TRACKER.md](PHASE_STATUS_TRACKER.md) (claim your task there: `IN_PROGRESS` + your name + date), `svn status`, and `saas-plan-doc/WORK_LOG.md` to see what other agents changed.
3. **After every work session**, append an entry to `saas-plan-doc/WORK_LOG.md`:
   - date and time;
   - agent / account;
   - task area;
   - files changed;
   - decisions needed;
   - next step.
4. Never overwrite another agent's work. If two changes conflict, stop and ask the owner.
5. Document edits: keep the existing style (marks CD-xx, `CODE-INSPECTED`, `LEGACY`, `PROPOSED (gap)`), and keep 16 sections per phase document.
6. Code: only after owner approval of the phase plan; follow the existing code style; run only local tests; never touch the protected hosts.
